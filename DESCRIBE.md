# Motd Show — Modrinth draft

**Title:** Motd Show
**Description:** Replies with the server MOTD.
**Command:** `/motdshow`

## Body

Replies with the server MOTD.

### Usage

`/motdshow` — run in game chat (OP level 0 / everyone can use it).

### Installation

1. Install Forge 47.4.20 for Minecraft 1.20.1
2. Drop the jar into your `mods` folder
3. Type `/motdshow` in chat
